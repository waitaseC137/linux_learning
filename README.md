## 🎮 OverTheWire — Bandit

[OverTheWire](https://overthewire.org/wargames/bandit/), Linux terminal becerilerini **oyun formatında** öğreten ücretsiz bir platform. Her level yeni bir komut veya kavram öğretiyor.

Çözümlerimi Türkçe olarak belgeledim — sadece "ne yapacaksın" değil, **"neden çalışıyor"** odaklı.

| Dosya | Konular | Level'lar |
|---|---|---|
| [bandit_0-10.md](./overthewire/bandit_0-10.md) | SSH, dosya okuma, find, grep, sort, uniq, strings | 0 → 10 |
| [bandit_11-20.md](./overthewire/bandit_11-20.md) | Base64, ROT13, hexdump, sıkıştırma, netcat, SSL, nmap, git, SUID | 11 → 20 |
| [bandit_21-33.md](./overthewire/bandit_21-33.md) | Cron, bash scripting, brute force, vim escape, git, shell variables | 21 → 33 |

## 🛠️ Nasıl Kullanılır?

1. [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) sitesine gir
2. Level sayfasındaki görevi oku
3. Önce **kendi başına dene** — takılırsan buraya bak
4. Çözümü okurken "neden?" sorusunu sormayı unutma

> Şifreler zaman zaman değişebilir. Bu rehberlerde yöntem anlatılıyor, şifreler paylaşılmıyor.
